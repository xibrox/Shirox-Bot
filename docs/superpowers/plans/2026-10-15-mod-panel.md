# /mod Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single `/mod` command that opens a private moderation panel (members, users by ID, bans, channel tools, history), sharing all moderation logic with the existing slash commands.

**Architecture:**
- **`lib/modHistory.js`:** stores moderation actions.
- **`lib/modActions.js`:** holds every moderation action as a function that returns `{ error }` or `{ publicLine?, notice? }`. The slash commands and the panel both call these.
- **Views:** each panel view is a module in `lib/mod/views/`.
- **`commands/mod.js`:** routes `mod:<view>:<action>[:<arg>]` and checks each action's permission.
- **History from events:** the events that already log bans, kicks, timeouts and honeypot actions now also record history.

**Tech Stack:** Bun, discord.js 14.27, `bun test`.

**Spec:** `docs/superpowers/specs/2026-10-15-mod-panel-design.md`

**Builds on:** the `/setup` v2 code. It uses `sendLog(guild, type, embed)`, `test/fakes.js` (with `client`/`channelId`) and `test/limits.js`.

## Global Constraints

- Use bun only. Commits use plain messages with **no** `Co-Authored-By`.
- `/mod`: no options, `setDefaultMemberPermissions(ModerateMembers)`, `setDMPermission(false)`, category `moderation`, ephemeral.
- Permissions for each action:

  | Actions | Permission |
  |---|---|
  | warn, warnings, timeout, untimeout, history, user by ID | ModerateMembers |
  | kick | KickMembers |
  | ban, unban, softban, bans list | BanMembers |
  | nickname | ManageNicknames |
  | roles | ManageRoles |
  | purge | ManageMessages |
  | lock/unlock, slowmode | ManageChannels |

- Fixed texts:
  - Denied: `❌ You need **<Permission>** for this.` (UI names via `permissionNames`)
  - Stale panel: `⚠️ This panel is out of date. Run /mod again.`
  - Unknown user: `❌ I can't find a user with that ID.`
- Slash commands keep their exact reply texts. Errors are ephemeral and results public.
- Panel results:
  - `publicLine` is sent to the channel with `allowedMentions: { parse: [] }`. That is the channel the panel was opened in, or the target channel for lock/unlock/slowmode.
  - The panel then re-renders with `error ?? notice ?? publicLine` as its notice.
- Panel views:
  - At most 5 rows, 25 options and 5 buttons per row.
  - Button labels at most 80 characters, modal input labels at most 45, modal titles at most 45, embed field values at most 1024, descriptions at most 4096.
  - Custom IDs start with `mod:` and are at most 100 characters.
- Code style: `lib/` and `test/` use double quotes and 4 spaces. `commands/` uses single quotes and 2 spaces.

## Review Focus

- **A member who leaves or is banned while their user view is open.** Member-only actions must answer `❌ That user is not in this server.` and re-render as a non-member, not crash (Task 6).
- **Hierarchy:** acting on someone with a role equal to or above yours, or the bot's, must be refused exactly as the slash commands refuse it (Task 2).
- **Softbans must appear once in history** (as `softban`), not also as ban/unban (Task 4).
- **History and warning lists with long reasons must stay within embed limits.** Reasons are truncated (Tasks 1, 7, 8).
- **Forms with bad input** (a duration like `5x`, an amount of `0` or `101`, a non-numeric user ID, delete-messages `3d`) must give a notice and change nothing (Tasks 6 and 8).

```js
const { loadJsonFile } = require("./jsonFile");

// { [guildId]: [{ type, targetId, moderatorId, reason, timestamp, extra }] }, oldest first
const store = loadJsonFile("mod-history");
const MAX_ENTRIES = 500;

const HISTORY_EMOJI = {
    warn: "⚠️", timeout: "🔇", untimeout: "🔊", kick: "👢", ban: "🔨", unban: "✅", softban: "🧹",
    purge: "🗑️", lock: "🔒", unlock: "🔓", slowmode: "🐢", honeypot: "🍯",
};

function recordAction(guildId, entry) {
    const list = (store.data[guildId] ??= []);
    list.push({ ...entry, timestamp: Date.now() });
    if (list.length > MAX_ENTRIES) list.splice(0, list.length - MAX_ENTRIES);
    store.save();
}

// Newest first, optionally only entries about one user
function getHistory(guildId, { targetId, limit = 25 } = {}) {
    return (store.data[guildId] || []).filter(e => !targetId || e.targetId === targetId).slice(-limit).reverse();
}

// "🔨 **ban** · <@user> · by <@mod> · reason · <t:…:R>"; channel actions show the channel instead of a user
function formatEntry(entry) {
    const target = entry.targetId ? `<@${entry.targetId}>` : entry.extra?.channelId ? `<#${entry.extra.channelId}>` : null;
    return [
        `${HISTORY_EMOJI[entry.type] ?? "•"} **${entry.type}**`,
        target,
        `by ${entry.moderatorId ? `<@${entry.moderatorId}>` : "unknown"}`,
        entry.reason ? entry.reason.slice(0, 100) : null,
        `<t:${Math.floor(entry.timestamp / 1000)}:R>`,
    ].filter(Boolean).join(" · ");
}

module.exports = { HISTORY_EMOJI, recordAction, getHistory, formatEntry };
```

```js
const { MessageFlags } = require("discord.js");
const { checkHierarchy, softban } = require("./moderation");
const { addWarning } = require("./warnings");
const { parseDuration, formatDuration } = require("./duration");
const { createLogEmbed, sendLog, userField, suppressLogsFor } = require("./logger");
const { recordAction } = require("./modHistory");

// Every action returns { error } or { publicLine } (and channel tools { notice }); callers decide where those go.

const MAX_TIMEOUT = 28 * 86_400_000;
const NOT_IN_SERVER = { error: "❌ That user is not in this server." };
const DELETE_WINDOWS = { "": 0, "0": 0, "1h": 3600, "24h": 86_400, "7d": 604_800 };

// Ban form's "delete messages from the last" field -> seconds, or null if it isn't one of the choices
const parseDeleteWindow = text => DELETE_WINDOWS[text.trim().toLowerCase()] ?? null;

// Slash commands: errors privately, results publicly (mentions never ping)
function replyResult(interaction, result) {
    if (result.error) return interaction.reply({ content: result.error, flags: MessageFlags.Ephemeral });
    return interaction.reply({ content: result.publicLine ?? result.notice, allowedMentions: { parse: [] } });
}

async function warnUser(interaction, user, reason) {
    if (user.bot) return { error: "❌ You can't warn bots." };
    if (user.id === interaction.user.id) return { error: "❌ You can't warn yourself." };
    const { guild } = interaction;

    const warnings = addWarning(guild.id, user.id, reason, interaction.user.id);
    const dmSent = await user.send(`⚠️ You were warned in **${guild.name}**. Reason: ${reason}`).then(() => true, () => false);
    recordAction(guild.id, { type: "warn", targetId: user.id, moderatorId: interaction.user.id, reason });
    const embed = createLogEmbed("warning", "⚠️ Member warned")
        .addFields(
            { name: "User", value: userField(user) },
            { name: "Moderator", value: userField(interaction.user) },
            { name: "Reason", value: reason },
            { name: "Total warnings", value: `${warnings.length}`, inline: true },
        );
    await sendLog(guild, "moderation", embed);

    return {
        publicLine: `⚠️ Warned **${user.tag}** (warning #${warnings.at(-1).id}, ${warnings.length} total). Reason: ${reason}` +
            (dmSent ? "" : "\n*(Couldn't DM them.)*"),
    };
}

async function timeoutMember(interaction, member, durationText, reason) {
    if (!member) return NOT_IN_SERVER;
    const error = checkHierarchy(interaction, member);
    if (error) return { error };
    if (!member.moderatable) return { error: "❌ I can't timeout that member." };

    const auditReason = `${interaction.user.tag}: ${reason}`;
    if (["off", "remove", "none", "0"].includes(durationText.trim().toLowerCase())) {
        await member.timeout(null, auditReason);
        return { publicLine: `🔊 Removed timeout from **${member.user.tag}**.` };
    }

    if (ms > MAX_TIMEOUT) return { error: "⚠️ The maximum timeout is 28 days." };
    await member.timeout(ms, auditReason);
    return { publicLine: `🔇 Timed out **${member.user.tag}** for **${formatDuration(ms)}**. Reason: ${reason}` };
}
```

```js
async function changeRoles(interaction, member, roles, adding) {
    if (!member) return NOT_IN_SERVER;
    for (const role of roles) {
        const error = checkAssignableRole(interaction, role);
        if (error) return { error };
    }
    const changing = roles.filter(role => member.roles.cache.has(role.id) !== adding);
    if (!changing.length) {
        if (roles.length === 1) return { error: adding ? `${member} already has ${roles[0]}.` : `${member} doesn't have ${roles[0]}.` };
        return { error: adding ? "Nothing to change: they already have those roles." : "Nothing to change: they don't have those roles." };
    }
    const reason = `By ${interaction.user.tag}`;
    await (adding ? member.roles.add(changing, reason) : member.roles.remove(changing, reason));
    const list = changing.map(String).join(", ");
    return { publicLine: adding ? `✅ Gave ${list} to ${member}.` : `✅ Removed ${list} from ${member}.` };

async function purgeMessages(interaction, channel, amount, userId) {
```

```js
const { SlashCommandBuilder, PermissionFlagsBits, MessageFlags } = require('discord.js');
const { VIEWS } = require('../lib/mod/views');
const { homeView } = require('../lib/mod/views/home');
const { OUT_OF_DATE, can, permissionReply } = require('../lib/mod/ui');

// Buttons, menus and forms use "mod:<view>:<action>[:<arg>]"
async function route(interaction, kind) {
  const [, viewId, action, arg] = interaction.customId.split(':');
  const view = VIEWS[viewId];
  const handler = kind === 'modal' ? view?.handleModal : view?.handleComponent;
  if (!handler || !view.actions || !Object.hasOwn(view.actions, action)) return interaction.reply(OUT_OF_DATE);
  // The panel is private, but permissions can change while it's open
  const permission = view.actions[action];
  if (permission && !can(interaction, permission)) return interaction.reply(permissionReply(permission));
  await handler(interaction, action, arg);
  // A handler that didn't recognise the action left the interaction unanswered
  if (!interaction.replied && !interaction.deferred) await interaction.reply(OUT_OF_DATE);
}

  category: 'moderation',

    .setName('mod')
    .setDescription('Open the moderation panel')
    .setDefaultMemberPermissions(PermissionFlagsBits.ModerateMembers)
    .setDMPermission(false),

  async execute(interaction) {
    await interaction.reply({ ...(await homeView(interaction)), flags: MessageFlags.Ephemeral });
  },

  handleComponent(interaction) {
    return route(interaction, 'component');
  },

  handleModal(interaction) {
    return route(interaction, 'modal');
```

```js
async function warningsView(interaction, userId, notice, confirmClear = false) {
    const user = await interaction.client.users.fetch(userId).catch(() => null);
    const warnings = getWarnings(interaction.guild.id, userId).slice(-25).reverse();
    const lines = warnings.map(w => `**#${w.id}** · <t:${Math.floor(w.timestamp / 1000)}:R> by <@${w.moderatorId}>\n${w.reason.slice(0, 120)}`);
    const embed = modEmbed(`📋 Warnings · ${user?.tag ?? userId}`)
        .setDescription((lines.join("\n\n") || "No warnings.").slice(0, 4000));

    const rows = [];
    if (warnings.length) {
        rows.push(new ActionRowBuilder().addComponents(new StringSelectMenuBuilder()
            .setCustomId(`mod:warnings:remove:${userId}`)
            .setPlaceholder("Remove a warning…")
            .addOptions(warnings.map(w => ({ label: `#${w.id} · ${w.reason.slice(0, 80)}`, value: String(w.id) })))));
    }
    rows.push(confirmClear
        ? rowOf(
            button(`mod:warnings:confirmclear:${userId}`, "Confirm clear", ButtonStyle.Danger),
            button(`mod:warnings:cancel:${userId}`, "Cancel"),
            homeButton(),
        )
        : rowOf(
            button(`mod:warnings:clear:${userId}`, "🗑️ Clear all", ButtonStyle.Danger).setDisabled(!warnings.length),
            button(`mod:user:show:${userId}`, "◀ Back"),
            homeButton(),
        ));
    return panel(embed, rows, notice);
}
```

```js
    const channel = interaction.guild.channels.cache.get(channelId) ?? interaction.channel;
    const locked = isLocked(interaction, channel);
    const slowmode = channel.rateLimitPerUser ?? 0;
    const embed = modEmbed("💬 Channel tools").setDescription([
        `**Channel:** ${channel}`,
        `**Locked:** ${locked ? "yes" : "no"}`,
        `**Slowmode:** ${slowmode ? formatDuration(slowmode * 1000) : "off"}`,
    ].join("\n"));
    const id = channel.id;
    return panel(embed, [
        new ActionRowBuilder().addComponents(new ChannelSelectMenuBuilder()
            .setCustomId("mod:channel:pick")
            .setPlaceholder("Pick another channel…")
            .setChannelTypes(ChannelType.GuildText, ChannelType.GuildAnnouncement)
            .setDefaultChannels([id])),
        rowOf(
            can(interaction, P.ManageMessages) && button(`mod:channel:purge:${id}`, "🧹 Purge"),
            can(interaction, P.ManageChannels) && (locked
                ? button(`mod:channel:unlock:${id}`, "🔓 Unlock", ButtonStyle.Success)
                : button(`mod:channel:lock:${id}`, "🔒 Lock", ButtonStyle.Danger)),
            can(interaction, P.ManageChannels) && button(`mod:channel:slowmode:${id}`, "🐌 Slowmode"),
            homeButton(),
        ),
    ], notice);
}

const field = (id, label, required, max, placeholder) => {
    const input = new TextInputBuilder().setCustomId(id).setLabel(label).setStyle(TextInputStyle.Short).setRequired(required).setMaxLength(max);
    if (placeholder) input.setPlaceholder(placeholder);
    return new ActionRowBuilder().addComponents(input);
};

const FORMS = {
    purge: ["Purge messages", [field("amount", "How many messages (1-100)", true, 3), field("user", "Only from this user ID (optional)", false, 20)]],
    lock: ["Lock channel", [field("reason", "Reason (optional)", false, 400)]],
    unlock: ["Unlock channel", [field("reason", "Reason (optional)", false, 400)]],
    slowmode: ["Slowmode", [field("duration", "Delay between messages", true, 10, "5s, 1m, 1h or off")]],
};

module.exports = {
    view: {
        id: "channel",
        actions: { show: null, pick: null, purge: P.ManageMessages, lock: P.ManageChannels, unlock: P.ManageChannels, slowmode: P.ManageChannels },

        async handleComponent(interaction, action, channelId) {
            if (action === "show") return interaction.update(await channelView(interaction, channelId ?? interaction.channelId));
            if (action === "pick") return interaction.update(await channelView(interaction, interaction.values[0]));
            const [title, fields] = FORMS[action] ?? [];
            if (!title) return;
            return interaction.showModal(new ModalBuilder().setCustomId(`mod:channel:${action}:${channelId}`).setTitle(title).addComponents(...fields));
        },

        async handleModal(interaction, action, channelId) {
            const channel = interaction.guild.channels.cache.get(channelId);
            const render = notice => channelView(interaction, channelId, notice);
            if (!channel) return interaction.update(await channelView(interaction, interaction.channelId, "❌ I can't see that channel."));

            let result;
            if (action === "purge") {
                const amount = Number(interaction.fields.getTextInputValue("amount").trim());
                const userId = interaction.fields.getTextInputValue("user").trim() || null;
                if (!Number.isInteger(amount) || amount < 1 || amount > 100) result = { error: "❌ The amount must be a number from 1 to 100." };
                else if (userId && !/^\d{17,20}$/.test(userId)) result = { error: "❌ That is not a valid user ID." };
                else result = await actions.purgeMessages(interaction, channel, amount, userId);
            } else if (action === "lock" || action === "unlock") {
                result = await actions.setLock(interaction, channel, action === "lock", interaction.fields.getTextInputValue("reason").trim() || null);
            } else if (action === "slowmode") {
                result = await actions.setSlowmode(interaction, channel, interaction.fields.getTextInputValue("duration"));
            } else return;
            // Lock and slowmode announce themselves in the channel they change
            return finishAction(interaction, result, render, channel);
        },
    },
};
```

```js
}
```
